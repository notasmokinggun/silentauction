# Welcome page photos

Drop the photos for the rolling welcome gallery in this folder, numbered:

```
1.jpg  2.jpg  3.jpg  ...
```

- Also accepted: `.jpeg`, `.png`, `.webp` (use any one per number).
- Numbers must be continuous: the site checks 1, 2, 3 ... and stops at the first
  missing number (up to 40).
- If there is no `1.*` file, the site keeps the original dark welcome background.
- Tips: portrait or square photos suit phones best. Keep each under about
  400 KB (around 1200 px on the long side) so the welcome page loads fast.
- Photos crossfade every few seconds behind a soft frosted card. No captions or
  credits are shown.
